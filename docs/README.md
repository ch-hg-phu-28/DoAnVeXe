# Tài liệu dự án

Nơi TV3, TV4 để sơ đồ và tài liệu. Mỗi sơ đồ lưu 2 file: bản gốc `.drawio` và ảnh `.png`, đặt tên theo mã trong file phân công.

```
docs/
├── so-do/        D01–D19, D28: use case, activity, sequence, state, wireframe khách hàng   (TV3)
├── database/     D20 ERD, từ điển dữ liệu B01–B22, ràng buộc, dữ liệu mẫu                (TV4)
├── thiet-ke/     D21–D27, D29: kiến trúc, triển khai, lớp, sơ đồ màn hình, wireframe quản trị (TV4)
└── quan-ly/      WBS, Gantt, biên bản họp, báo cáo tiến độ
```

Ví dụ tên file: `so-do/D01_UseCaseTongQuat.drawio`, `so-do/D01_UseCaseTongQuat.png`.
